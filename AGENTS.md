# AGENTS.md · вход для любого агента

Читают все: Claude Code, Codex, облако и терминал. `CLAUDE.md` это ссылка на этот файл

1. Прочитай `README.md` целиком: это **единственный документ задачи** (наряд). Исполняй фазы сверху вниз, автономно
2. Прочитай навыки из таблицы «Skills required» в README; первая строка каждого отчёта: `Skills applied: <список реально прочитанных>`
3. Окружение: `bash tools/setup.sh` (python, node, playwright + Chromium, хук чистоты)
4. Отчёт пишется секцией «Журнал» в конце README: по строке на пункт, с хешем коммита и последней строкой гейта. Соседних отчётов не плодить; споры и `needs-human` в `NOTES.md`
5. Субагенты только на чтение, не больше трёх. Строит один исполнитель

## Репо публичный: закон чистоты

- Имён клиента и людей нет ни в файлах, ни в коммитах, ни в комментариях. Проверка `python3 tools/clean_check.py` (список хешами в `tools/names.h16`), хук `.githooks/pre-commit` блокирует коммит
- Папка `private/` (если есть на машине владельца) в `.gitignore` и не коммитится никогда; в облаке её нет, и она не нужна: наряд самодостаточен
- Шрифты только OFL (`vendor/fonts/`), чужих картинок нет, бренд входит только через `src/tokens.scene.js`

## Язык и тон

Заметки и Журнал по-русски, коротко, без воды. Всё, что видно на экране сцены, по-английски
