Приказ владельца, отменяет PR и ручное слияние. Думай и собирай сам, результат приноси сам прямо на https://robvagin.github.io/relief-diagrams/. После каждого рабочего шага: python3 tools/clean_check.py, затем git pull --rebase origin main, затем git push origin HEAD:main. Pages публикует main сам. Если push в main отклонён, пушь в свою ветку cloud/<твой кусок>; сессия playground первым делом кладёт .github/workflows/automerge.yml (push в cloud/** вливается в main, затем gh workflow run pages.yml --ref main), и ветка доедет сама. Журнал не в README, а в cloud/journal/<твой кусок>.md, чтобы пять сессий не сталкивались. Каждая проба в своей папке lab/<сцена>/v<N>.html, только свои файлы из таблицы приказа. Первый push как только что-то открывается в браузере, полноты не жди. В конце журнала: ссылка на свою часть на Pages и что осталось.
