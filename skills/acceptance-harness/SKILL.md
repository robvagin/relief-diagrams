# Харнесс приёмки

За пятнадцать проектов написано около **сорока** харнессов — от `outputs/verify-harness.js` (07.07) через `client-rc/_tools/verify_all.py`, `data2d/src/audit.js`, `guilloche-dash/verify/audit.py`, пять `guilloche-workers/verify-*.py` и `GALLERY-2026-09-04/audit.js` (49 проб) до `client/info-block-2026-09-03/harness/acceptance.py` (08.09). Каждый раз с нуля, каждый раз одни грабли: «Восемь ловушек» из `GALLERY/WORKING.md` и §5 из `handoff_delegate.md` — один список, написанный дважды с разницей в неделю.

Здесь не набор проверок, а **метод постройки**: чтобы харнесс мерил реальность, не терял результаты и падал там, где надо.

## Часть 1. Три закона

### З1 🔴 — отрицательный контроль

`ПЛАН_УПАКОВКИ_ФЛОТА_2026-09-05.md` §6: «Харнесс — подозреваемый номер один: **проба принимается, когда её сломали нарочно и она упала**». Проба, которая ни разу не падала, — украшение. Зелёный столбец из тридцати таких — тридцать украшений.

У каждой пробы есть **грязный дубль**: копия артефакта с намеренно внесённым ровно тем дефектом, который проба ловит. Тридцать секунд, одна подмена строки:

| проба | грязный дубль |
|---|---|
| внешних ссылок нет | `<script src="https://cdn.example.com/x.js">` перед `</head>` |
| сырых `range` нет | `<input type="range">` перед `</body>` |
| хардкода цвета нет | `ctx.strokeStyle = '#ff00aa';` в сцену |
| детерминизм по сиду | скрипт, рисующий пиксель по `Math.random()` через 250 мс |
| канвас жив | `window.requestAnimationFrame = function(){return 0}` в `<head>` |
| канвас не пуст | `canvas{visibility:hidden}` либо `clearRect` по `load` |
| ошибок консоли нет | `setTimeout(()=>{throw new Error('поломка')},60)` |
| паспорт полон | удалить обязательный ключ из json |
| кириллицы в атрибутах нет | `<canvas data-имя="сцена">` |

Два способа держать это в коде:

1. **Путь артефакта — переменная окружения.** В `GALLERY/audit.js` это `GALLERY_SHEET=<path> node audit.js`: «run it against the build it was written to catch and watch it go red». Инфраструктуры не нужно, работает с первого дня.
2. **Реестр несёт рецепт грязи.** Проба регистрируется вместе с `dirty(text) -> text`, а `--selftest` строит чистый образец, подсовывает каждому дублю свою поломку и требует красного. Так сделан `scripts/harness.py`: десять файловых проб доказаны за две секунды, без сети и браузера.

🔴 Пробу браузера тоже надо доказать — её дубль просто ждёт Chromium. До тех пор она честно `skip`, а не зелёная.

Что это не теория: проба «в файле нет кириллицы» была прогнана на старой русской версии и упала с «11 191 символ». После этого её вердикт стал что-то значить.

### З2 🔴 — закон мержа

`handoff_delegate.md` §5.2: «**Частичный прогон обязан МЕРЖИТЬ.** Проба, дамп и нормализация затирали свои файлы — **три отдельных случая за одну сессию**». Цена: `probe_modes.py audio-vj` оставлял `techniques.json` c одной строкой, и следующая съёмка молча снимала одну карточку из ста сорока.

```
результат  = { артефакт → { id пробы → {ok, exp, act, ts, mtime} } }
запись     = temp + os.replace   (атомарно, в той же папке)
повтор     = перезаписывается ТОЛЬКО клетка (артефакт × проба), которая бежала
выбывшее   = строка удаляется, если артефакта нет на диске или проба снята
             с реестра  ← иначе фантомные строки
чтение     = битый JSON НЕ затирается, а роняет прогон с кодом 2
```

- **Ключ по артефакту, а не по прогону** — список «последнего запуска» не мержится в принципе.
- **temp + rename** — `write_text` посреди Ctrl-C это полузаписанный json, то есть потерянный прогон всего флота.
- **Чистка выбывшего** — когда spheregen пошёл с одной карточки на пять, старая строка выжила бы шестой, фантомной.
- **Печатать, сколько сохранено и сколько переписано** — молчаливый мерж неотличим от молчаливого затирания.

### З3 🔴 — замер возвращает то, что в него заложили

`GALLERY/TRIAGE.md`, Н1: просмотрщик резал кадр, видно было 38–64 % картинки. «🔴 **Мой первый замер этого не увидел**, потому что я вычислял нарисованный размер по формуле `contain` вместо того, чтобы померить коробку картинки. **Замер вернул то, что я в него заложил**».

1. **Положительный контроль на синтетике.** Сперва померь то, где ответ известен: доля непрозрачных пикселей на залитом прямоугольнике = 1.0, на пустом канвасе = 0.0. Не дала — сломан замер, а не сцена. Так же устроена калибровка машины в `canvas-frame-budget`.
2. **Диапазон-санити.** У метрики есть значения, означающие «сломался прибор», а не «плохой результат»: доля `0.0` — скорее всего WebGL без `preserveDrawingBuffer`; доля `1.0` — залитый фон, меряем не сцену. Оба отбиваются отдельной веткой с отдельным текстом, а не общим порогом. В `harness.py` это чистая функция `verdict_share()`, и селф-тест проверяет её шестью случаями **без браузера**.
3. **Два независимых способа.** Коробка: формула `contain` против `getBoundingClientRect()`. Живость: доля пикселей против счётчика `__FRAMES`. Расхождение — находка, и врёт почти всегда тот способ, который вычисляет, а не тот, который меряет.

Обратная сторона (§5.10): «Прежде чем чинить кадр по красному гейту — проверь сам гейт, но проверь **замером**. Гипотеза была правдоподобной и ложной: гейт был прав, кадр был плох».

## Часть 2. Анатомия харнесса

| часть | что делает | правило |
|---|---|---|
| **обнаружение** | находит артефакты по пути/маске | пустой список — **код 2**, а не «всё зелено» |
| **проба** | одна проверка = одна функция → `(ok, ожидание, факт)` | не знает про соседей, не чинит артефакт |
| **сборка** | вердикты в JSON по ключу артефакта | мерж по З2, атомарная запись |
| **отчёт** | таблица `проба · ожидание · факт · вердикт` | **никаких проверок внутри отчёта** |
| **код возврата** | `0` закрыто · `1` красное · `2` харнесс сломан · `3` не всё доказано | машина читает код, человек — таблицу |

🔴 **Проверка внутри отчёта — главная порча харнесса.** Как только `if` переезжает в печать, проба перестаёт существовать как объект: её не посчитать, не прогнать поодиночке, не доказать грязным дублем.

🔴 **Счётчик проб.** `EXPECTED_PROBES = 49` в `GALLERY/audit.js`: если их в прогоне меньше — красная строка. Проба, выпавшая из прогона, — не проба, которая прошла. Число меняется **вместе** с новой пробой, а не вместо неё.

🔴 **Охват.** Проба докладывает, СКОЛЬКО проверила. Цикл, молча пропустивший все ряды через `if(!key) continue`, отчитается `dead: []` и будет выглядеть зелёным.

**Код 3 нужен отдельно:** «красного нет» ≠ «приёмка закрыта». Три пробы, пропущенные без Chromium, — не победа.

**Протухание.** Строка результата хранит `mtime` артефакта; файл правили после прогона — вердикт `stale`, в зелёные не идёт. Зелёное от позавчерашней версии опаснее красного.

## Часть 3. Виды проб под наш материал

**1 · Живость канваса (не blank-render).** Нарисован ≠ жив. Два кадра с разницей ~400 мс, оба сведены в offscreen через `drawImage` (годится и для 2D, и для WebGL), затем `getImageData`:

```js
let opaque = 0, hash = 0x811c9dc5;
for (let i = 0; i < d.length; i += 4) if (d[i + 3] > 8) opaque++;   // непустота
for (let i = 0; i < d.length; i++) { hash ^= d[i]; hash = Math.imul(hash, 0x01000193) >>> 0; }
```

Критерий: `0.004 ≤ доля непрозрачных < 1.0` **и** хеши двух кадров различаются. Порог `0.004` — из `shoot.py`: ниже него кадр помечается `EMPTY` и на лист не ставится. Верхняя граница нужна не меньше нижней.

**2 · Детерминизм по сиду.** Тот же FNV-1a по пиксельному буферу, два независимых прогона `?seed=7`, пауза одинаковая: один сид → один отпечаток. Статический спутник — `Math.random(` и `Date.now(` в сцене = 0: ловит недетерминизм грепом, без браузера.

**3 · Ошибки консоли и reject'ы.** `pageerror` + `console.error` + `unhandledrejection` = 0. Слушатели вешать **до** `goto`, иначе ранние ошибки не попадут в счёт.

**4 · Целостность single-file.** Ни одной ссылки `src`/`href`/`url()` мимо `data:`/`#`/`blob:`, ни `fetch`/`importScripts`/`new Worker` наружу — и обратная половина: то, что должно быть **вшито**, вшито (шрифт, кадр, пресет). Ловушка: `url(` без взгляда назад ловит `createObjectURL(` и выдаёт внешнюю ссылку на ровном месте. Ложное срабатывание опаснее пропуска — из-за него отключают пробу целиком.

**5 · Состояния UI** — брать `ui-state-completeness`, не дублировать.
**6 · Перф** — брать `canvas-frame-budget` и его `scripts/perf-probe.js`, не дублировать.

**Проба из жалобы.** Жалоба владельца превращается в проверяемое утверждение и живёт в харнессе дословно. Ставшая пробой — не возвращается; оставшаяся в переписке — возвращается через две итерации.

## Часть 4. Инструментарий

| вопрос | чем мерить | почему |
|---|---|---|
| канвас, пиксели, живость, детерминизм, перф | **Playwright + Chromium** | единственное, что реально рисует |
| раскладка, обрезки, контраст, `getBoundingClientRect` | **Playwright + Chromium** | геометрию знает только настоящий движок |
| математика ядра, инварианты, круговой рейс конфига | **jsdom** | секунды вместо десятков, GPU не нужен |
| структура файла, вшитость, греп, паспорта, размеры | **чистый python3** | ноль зависимостей, идёт везде |
| пакет, распаковка, замыкание ссылок | **python3 + zipfile** | приёмка «из чистой распаковки, без сети» |

🔴 **Где jsdom врёт.** Он не рисует — пикселей у канваса нет, и любая проба живости на нём вечнозелёная. У него нет раскладки — `scrollWidth`, `clientWidth`, `getBoundingClientRect()` дают нули, и проверка обрезок проходит всегда. У него нет SVG-геометрии — `getTotalLength()`, `getBBox()` отсутствуют, интейк SVG «работает» вхолостую. Всё про пиксель и геометрию — только Chromium; jsdom остаётся для чистой логики.

```bash
pip3 install playwright && python3 -m playwright install chromium   # python-харнесс
npm install playwright  && npx playwright install chromium          # node-харнесс
```

`~/.playwright-mcp` есть, но у node и python **свои** копии — наличие одной не даёт другой. `GALLERY/audit.js` поэтому ищет playwright по четырём путям и печатает инструкцию вместо стектрейса.

Две ловушки среды: `document.styleSheets[].cssRules` по `file://` роняет **SecurityError** — правила CSS проверять по исходнику; `const LAST = …` на верхнем уровне классического скрипта **не** становится свойством `window` — обращаться по голому имени под `typeof X !== 'undefined'`, иначе `window.LAST` вернёт null и проба «пройдёт».

## Часть 5. Скелет — `scripts/harness.py`

python3, stdlib, идёт на системном питоне macOS из коробки; Playwright опционален.

```bash
python3 scripts/harness.py движок.html               # полный прогон
python3 scripts/harness.py ФЛОТ/ --json флот.json    # папка целиком
python3 scripts/harness.py --only hardcode,panel …   # частичный прогон, МЕРЖИТ
python3 scripts/harness.py --report                  # отчёт из накопленного
python3 scripts/harness.py --selftest                # 🔴 отрицательный контроль
python3 scripts/harness.py --list                    # реестр проб
```

Внутри: реестр `PROBES` с декоратором `@probe(id, title, needs, dirty)`, тринадцать проб (десять файловых + три браузерных), `PROBE_COUNT` как счётчик охвата, мерж с `temp + os.replace`, таблица, коды `0/1/2/3`, пометка `stale` по `mtime`.

**Новая проба — четыре строки:**

```python
@probe('my-check', 'что проверяет',
       dirty=lambda t, d: t.replace('маркер', 'сломанный маркер', 1))   # ← дубль ОБЯЗАТЕЛЕН
def p_my_check(a):
    n = len(re.findall(r'...', a.body))        # a.body — текст без base64-нагрузки
    return Res(n == 0, 'ожидание словами', str(n))
```

Дальше поднять `PROBE_COUNT` на единицу и прогнать `--selftest`. Пока дубль не покраснел, пробы нет.

Учтено в каркасе: `a.body` срезает base64 (иначе четырёхбуквенное совпадение внутри вшитых кадров даёт ложные срабатывания на девяти мегабайтах), `a.markup` срезает и тела `script`/`style` (иначе `if(a<b)` читается как тег), битый накопленный JSON роняет прогон, а не переписывается.

## Часть 6. Десять пунктов приёмки движка

Движок закрыт, когда **все десять** зелёные. Не «в основном». Сегодня: **D2 — 10/10, остальной флот — 4–6/10**.

| # | Пункт | Проба | Команда |
|---|---|---|---|
| 1 | Один файл, ноль сети | внешних ссылок 0, офлайн из `file://` | `--only single-file` |
| 2 | Панель по канону | `kit-panel` verbatim, сырых `input[type=range]` 0 | `--only panel` |
| 3 | Ноль хардкода | хексов вне токен-блока 0 | `--only hardcode` |
| 4 | Детерминизм | один сид → один FNV-отпечаток, дважды | `--only no-random,determinism` |
| 5 | Живость счётчиками | `__FRAMES`/`__READY`/`__ERROR` + доля пикселей и разница кадров | `--only liveness,canvas-alive` |
| 6 | Покой движения | `prefers-reduced-motion`: ход снят, кадр на месте | `--only calm` |
| 7 | Фрагмент | `?embed=1` прячет панель, 320×240 не разваливается | `--only fragment` |
| 8 | Экспорт | PNG (и SVG, где вектор) один-в-один с экраном | `--only export` |
| 9 | Паспорт | `паспорт.json`: id, семейство, суть, оси, размер | `--only passport` |
| 10 | Чисто | имён 0, лицензионных шрифтов 0, кириллицы в атрибутах 0 | `--only clean` |

Пункты 5–8 доказываются до конца только в Chromium: статическая половина ловит заявку, браузерная — исполнение. Заявка без исполнения это код 3, а не 0.

Брендинг по пункту 10 прячется в **четырёх** местах: имена, хексы, RGB-триплеты, вшитые base64 — грепаются все четыре. Список запретных имён хранится **хешами**, иначе сам харнесс становится упоминанием и роняет тот закон, который проверяет. Шрифт проверяется по `cmap`, не по названию.

## Анти-слоп

- Проба, которая ни разу не падала.
- Частичный прогон, затирающий файл результатов; `write_text` вместо `temp + rename`.
- Проверка внутри печати отчёта.
- Прогон без счётчика проб: выпавшая проба выглядит как прошедшая.
- Проба без охвата: `dead: []` при нуле проверенных рядов.
- Пустой список артефактов, отчитавшийся «всё зелено».
- Канвас, судимый в jsdom.
- Метрика без диапазон-санити: `0.0` и `1.0` приняты за результат.
- Вычисленное вместо померенного (формула `contain` вместо коробки).
- Зелёное от прошлой версии файла — без сверки `mtime`.
- Ложное срабатывание, оставленное «на потом»: из-за него отключают пробу целиком.
- Греп по всему файлу вместе с base64-нагрузкой.
- «RED» без числа в колонке «факт» — чинить нечем.

## Границы

- **`page-audit-runner`** — готовый прогон семи линз по одной странице; берётся как есть, когда артефакт это страница. Здесь — как построить приёмку, когда линзы нет.
- **`canvas-frame-budget`** — только перф; его `perf-probe.js` вызывается из харнесса, не переписывается.
- **`ui-state-completeness`** — матрица состояний; берётся пробой.
- **`external-audit-triage`** — приём ЧУЖОГО аудита: там судят нас, здесь мы строим суд.
- **`single-file-delivery-canon`** — что значит «один файл»; харнесс проверяет, правила задаёт тот канон.
- **`generative-fragment-handoff`** — контракт фрагмента и паспорт; пункты 7 и 9 оттуда.

## Файлы

- `scripts/harness.py` — реестр проб с грязными дублями, мерж с атомарной записью, таблица, коды `0/1/2/3`, `--selftest` с отрицательным контролем. Тринадцать проб под канвасный движок; под другой артефакт меняется реестр, каркас не трогается.
