# Обложки канвасных сцен

Набор превью читается как система не тогда, когда каждая картинка хороша по отдельности,
а когда у всех совпадают три вещи: **вес объекта, фон и поля**. Ниже — как это получить.

## Закон №1 — масштаб меряется ВЕСОМ, не рамкой 🔴

Габаритная рамка (bbox) врёт. У шара она облегает тело; у схемы с выносками она вдвое шире
самой графики; у сетки-поля она равна кадру. Подогнав все объекты «по рамке», получаешь набор,
где шар весит вдвое больше схемы — и это видно глазом сразу, а метрика молчит.

**Меряй покрытие:** доля пикселей кадра, реально отличающихся от фона. Подбирай масштаб
бинарным поиском под общий целевой вес.

```
цель ≈ 17–20% кадра для набора смешанных сцен
```

Разрежённые сцены (тонкие линии, редкие точки) до цели не дотянут даже на максимуме —
это нормально: они упрутся в потолок масштаба (0.94 кадра), и разброс 10–20% всё равно
вчетверо ровнее, чем «по рамке».

**Альтернатива для однородных наборов:** выбрать эталонный объект (шар) и держать у всех
одну долю высоты кадра — 62% работает хорошо.

## Закон №2 — единый фон

Каждая сцена рисует свой грунт: чуть светлее, чуть темнее, с другим подтоном. В сетке карточек
это читается как «каждая плитка своего цвета».

**Ретон:** `новый_пиксель = пиксель − фон_кадра + общий_грунт`. Объект сохраняет свои тона,
фон переносится в общий. Поля вокруг вписанного кадра заливай тем же грунтом — иначе шов.

Фотография — исключение: её не ретонишь, но тонируй под палитру (тёплый/холодный сдвиг)
и ставь в наборе **последней**, иначе растр выбивается из векторных соседей.

## Закон №3 — кроп только пропорциональный

Вырезать квадрат и вписать в 16:10 = растянутая сфера. Всегда считай целевую рамку в
пропорции контейнера и двигай её вокруг центра контента.

## Закон №4 — ничего не режется

Поле ≥6% кадра. Проверяй, что внутренние элементы сцены — плашки, легенды, выноски, подписи —
не липнут к кромке: у сцены могут быть свои поля, и после кропа они исчезают.

## Закон №5 — чисти артефакты

В кадр лезут: линии-разделители карточек галереи, панель управления, служебные мини-канвасы
(motion-pad, кривая easing), белые плашки-призраки от удалённых блоков. Всё это — не сцена.
Чисти до грунта порогом близости к фону; крупные плашки лови детектором однородных светлых
колонок и обрезай.

## Процедура съёмки

1. Файлы сцен скопируй в рабочую папку (сцены обычно self-contained single-file).
2. Playwright + системный chromium, флаг `--use-gl=angle` — иначе SwiftShader даёт 3 кадра
   за секунду и WebGL-сцена не успевает нарисоваться.
3. **DPR 2 для 2D-канваса, DPR 1 для WebGL.** На удвоенном разрешении тяжёлая WebGL-сцена
   (three.js + transmission) валит `page.screenshot` по 30-секундному таймауту. Замерено.
4. Дай сцене поработать 4–6 с (сборка, автоигра, оседание физики).
5. Панель убирай **удалением из DOM**, не `display:none` — потом снимай самый большой канвас
   как элемент. Иначе в кадр попадёт либо панель-оверлей, либо служебный мини-канвас.
6. Много приёмов на одной странице (галерея) — снимай канвасы поштучно через
   `scroll_into_view_if_needed` + `element.screenshot`, длинные страницы иначе клипаются.

## Если сцены нет, а есть готовая витрина

Превью вынимаются из HTML-витрины по **последнему data-URI ПЕРЕД упоминанием файла**:
`<img>` стоит до тела карточки, поэтому «ближайший по расстоянию» даёт соседнюю карточку.

## Скрипты

- `scripts/capture.py` — съёмка сцен (DPR-разделение, чистка DOM, поэлементные кадры).
- `scripts/normalize.py` — нормализация: вес, ретон, пропорциональный кроп, коллажи.

Оба параметризуются списком сцен сверху файла; правь список, не логику.

## Приёмка набора

Собери контактный лист всех обложек в один PNG и посмотри на него целиком — разнобой виден
только в наборе, не поштучно. Проверь: одинаковый ли фон · одинаково ли «тяжелы» объекты ·
нет ли обрезанных подписей · нет ли артефактов панелей · читается ли каждая в размере плитки
(уменьши до реальной ширины карточки, а не смотри в полный размер).

## Грабли

- Скриншот в полный размер обманывает: обложка живёт в плитке 280–450 px, проверяй в этом размере.
- `document.styleSheets[].cssRules` по `file://` падает SecurityError — проверяй CSS по исходнику.
- Локальный сервер пользователя (`127.0.0.1:*`) из облачной песочницы недостижим — работай с файлами.
