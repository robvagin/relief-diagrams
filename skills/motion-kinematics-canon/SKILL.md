# Кинематика движения — законы и стенд

## Зачем этот скилл

Канвасная фигура, которая «дёргается», почти никогда не дёргается из-за плохого изинга.
Она дёргается потому, что где-то в коде **рвётся производная**: скорость меняется скачком,
модуль синуса даёт излом, фаза жеста обрывается на полном ходу, цикл не приходит в себя.

Глазом это ловится плохо и спорно («вроде норовит»), а замером — за секунду и однозначно.
Здесь оба слоя: чем это лечится и чем это меряется.

Выковано на галерее анимаций знака client (42 приёма, август 2026): по замеру было
22 приёма с дефектами, стало 12, и все оставшиеся — намеренная резкость.

---

## ЗАКОН 1 · Задавай скорость, а не позицию

🔴 **Главный закон.** Если пишешь `angle = f(t)` кусочно по фазам — рывок появится
на каждом стыке, и никакой изинг его не уберёт.

Пиши **профиль скорости** `w(x)`, а угол бери интегралом:

```
угол(ph) = TAU · turns · I(ph) / area,   где I = ∫w, area = ∫w за весь цикл
```

Профиль скорости — трапеция со сглаженными склонами:

```js
// разгон smoothstep на [0,a] · плато на [a,b] · торможение smoothstep на [b,c] · покой
var A1 = a*0.5, A2 = (b-a), A3 = (c-b)*0.5, area = A1 + A2 + A3, I;
if(ph < a){ var u = ph/a;  I = a*(u*u*u - u*u*u*u/2); }          // ∫smoothstep, аналитически
else if(ph < b){ I = A1 + (ph-a); }
else if(ph < c){ var v = (ph-b)/(c-b);
  I = A1 + A2 + (c-b)*(v - (v*v*v - v*v*v*v/2)); }
else I = area;
```

Интеграл считается **аналитически**, не численно: `∫₀¹ smoothstep = 0.5`,
частичный `= u³ − u⁴/2`. Численная сумма на каждом кадре — расточительство и дрожь.

Скорость нулевая на обоих концах цикла ⇒ стык цикла невидим ⇒ **рывок невозможен по построению**.

**Как выглядит нарушение:** знак крутится и мгновенно встаёт. Замер: разрыв 0.58 об/с
при максимуме 1.23 — то есть тормозит с половины полного хода за один кадр.

---

## ЗАКОН 2 · Цикл обязан замыкаться

Анимация, которая не приходит в исходное состояние, на стыке даёт прыжок — раз в цикл,
и он всегда заметен именно потому, что редкий.

- **Вращение:** за цикл ровно **целое** число оборотов. `turns = Math.max(1, Math.round(P.spins))`.
  Дробное число оборотов = знак приходит боком.
- **Несколько частот в одном приёме:** все кратны периоду цикла. `sin(3w), sin(2w+1.1), sin(5w+0.4)`,
  где `w = TAU·(t % per)/per` — рисунок остаётся сложным, но за период сходится в себя.
  Несоизмеримые частоты (`sin(3.1t)`, `sin(2.3t)`) дают «никогда не повторяется» — и никогда не сходится.
- **Затухающие процессы** (маятник, пружина): хвост гасится до нуля явным множителем
  `out = 1 - smooth(clamp((u-0.82)/0.18, 0, 1))`, иначе в конце остаётся 3% размаха,
  а в начале цикла снова полный — это телепорт.
- **Одноразовые входы** (пробуждение, появление): либо держат финальное состояние,
  либо цикл = вход + пауза + **мягкий уход**. Сброс из «готово» в «пусто» за кадр — брак.

---

## ЗАКОН 3 · Где модуль — там излом

`Math.abs(Math.sin(...))` — самый частый источник дёрганья. В нижней точке производная
меняет знак скачком: физически это удар, визуально — щелчок.

| Что это по смыслу | Чем писать |
|---|---|
| Подъём/спад, дыхание, крен, отход блика | `k*k` или `sin²` — тот же размах, гладкое дно |
| Настоящий удар (мяч о пол, отскок) | модуль оставить — там разрыв скорости честный |

Нормировка при замене: `|y|` с максимумом 0.5 → `2·y²` (совпадает по максимуму).

## ЗАКОН 4 · Жест не обрывается на полной скорости

`k = ph < 0.34 ? Math.sin(TAU·ph/0.34) : 0` — значение непрерывно (sin 2π = 0),
но **скорость на выходе максимальна**. Жест кончается ударом.

Лечится оболочкой, гасящей скорость на обоих концах:

```js
var u = clamp(ph/0.34, 0, 1);
var k = Math.sin(TAU*u) * Math.sin(Math.PI*u);   // производная = 0 в u=0 и u=1
```

Амплитуда падает примерно до 0.8 — компенсируется параметром, не отказом от оболочки.

---

## ЗАКОН 5 · Один жест — одна остановка, и она в конце

Классический брак: разогнался → затормозил → **пауза** → поехал обратно → встал.
Читается как «тупит»: две-три остановки внутри одного движения.

Правильно: **торможение и возврат — один кусок**. Фигура выкатывается обратно, замедляясь,
и приезжает на место ровно в тот момент, когда движение гаснет:

```
уход · плато · [торможение + возврат одновременно] · покой
```

Позиция возвращается той же кривой, что гасит скорость:
`pos = 1 - smooth((ph-b)/(c-b))` на том же интервале, где `w` падает с 1 до 0.

Покой оставляется только в конце цикла и делается **параметром** — Роб сам решит, сколько стоять.

## ЗАКОН 6 · На границе фазы совпадают значение И скорость

Кусочная функция обязана сшиваться дважды. Типичная ошибка — присед в прыжке:

```js
// БРАК: на входе в фазу discScale скачет с 1 на 0.96
s.discScale = 1 - 0.04*Math.max(0, Math.cos(Math.PI*u2));

// ВЕРНО: два присела — на отрыве и на посадке, ноль на границах, скорость тоже ноль
var sq = 4*h*(1-h); sq *= sq;        // h = sin(pi*u2), высота прыжка
s.discScale = 1 - 0.055*sq;
```

`4h(1−h)` даёт ноль на концах фазы и горбы у отрыва/приземления; квадрат добавляет
нулевую производную на концах.

---

## ЗАКОН 7 · Знак возвращается на свою посадку

Если у фигуры есть каноническое положение детали (блик на своём месте, стрелка вверх),
любой приём обязан привести её туда же. Радиус и угол интерполируются от канонических
значений, а не задаются жёстко:

```js
var rr = lerp(Math.hypot(HL_X0, HL_Y0), P.r/100, env);   // из посадки на орбиту и обратно
```

`env` — включённость жеста: 0 в покое, 1 в разгаре. Тогда в покое деталь физически
не может оказаться не на месте.

---

## ЗАКОН 8 · Тема двигает фон и контакты, не саму фигуру

В инверсии знак остаётся собой. Меняются только:
- фон интерфейса;
- **тень** (её цвет и плотность);
- **элементы, которые идут ПО ФОНУ** — лучи, линии связи, подписи: тёмный штрих
  по тёмному фону исчезает, поэтому цвет берётся от темы.

Заливка и блик — от дневной палитры всегда. Иначе в инверсии знак перестаёт быть знаком.

---

## ЗАКОН 9 · Габарит движения определяет масштаб

Приём с большим ходом не должен упираться в край поля — и не должен заставлять
уменьшать ВСЕ фигуры. Габарит считается численно, один раз на приём:

```js
function roomOf(id, params){
  var mx = 1, my = 1;
  for(var i=0;i<=96;i++){
    var s = state(id, i*0.137, params, {x:1,y:1});
    var sc = (s.scale||1) * Math.max(s.sx||1, s.sy||1), ray = 0;
    if(s.outRays) for(var j=0;j<s.outRays.length;j++) ray = Math.max(ray, s.outRays[j].len + GAP);
    var ext = sc*(1 + ray) + 0.06 + (s.halo||0)*0.42;   // + свечение и мягкий край
    mx = Math.max(mx, Math.abs(s.x||0) + ext);
    my = Math.max(my, Math.abs(s.y||0) + ext);
  }
  return { x:mx, y:my };
}
// R = min(базовый, W*0.47/room.x, H*0.47/room.y)
```

Кэш сбрасывается при движении ручки. Свечение и лучи учитывать обязательно — они уходят
за диск и первыми касаются края.

# СТЕНД · чем это меряется

Глаз спорит, замер — нет. Готовые скрипты в `references/`, гоняются
через headless Chromium (playwright) по собранной странице.

## Служебные входы — открыть в странице заранее

Без них замерять нечего. В бою не мешают, весят ноль:

```js
window.__probe(id, t)   // состояние в момент t, БЕЗ отрисовки — основа всех замеров
window.__fxlist()       // список приёмов с декларациями ручек
window.__vals(id)       // текущие значения ручек
window.__freeze(t)      // точный кадр: пауза + перемотка (для снимков)
window.__jump(t)        // перемотка без паузы
```

## Метрика, которая не врёт: сходимость по сетке

🔴 **Порог, нормированный на амплитуду, путает разрыв с быстрым движением.**
Шесть колебаний за полсекунды дают большой `|Δ|` на шаге сетки — и ложную тревогу.

Правильный тест — сравнить сетку N и 2N:

| Величина | Гладкая функция | Разрыв позиции (C0) | Излом скорости (C1) |
|---|---|---|---|
| `max|Δ|` при удвоении N | падает вдвое | **остаётся** | падает вдвое |
| `max|Δ²|` при удвоении N | падает вчетверо | — | **падает вдвое** |

```js
if(m1b/m1a > 0.72) → РАЗРЫВ позиции          // не сошлось — значит настоящий скачок
else if(m2b/m2a > 0.40) → излом скорости
```

## Замкнутость — не в одной точке, а в восьми

Сравнивать `state(0)` и `state(period)` мало: совпадение может быть случайным.
Берём 8 точек `q ∈ {0, .13, .27, .41, .55, .69, .83, .96}` и сравниваем `state(q·per)`
с `state(q·per + per)`. Для угла — по модулю TAU, допуск в радианах (0.05), а не в долях амплитуды.

Приём может жить на **кратном** периоде — проверять ×1…×6, прежде чем звать это дефектом.

## Вращение меряется в оборотах в секунду

Для угла нормировка на амплитуду бесполезна (амплитуда = 25 рад, разрыв = 0.04 рад,
относительная величина ничтожна — а глазу это резкая остановка). Меряем физически:

```
vmax  = max|dφ/dt| / TAU        об/с
разрыв = max|Δv| / TAU          об/с
доля  = разрыв / vmax           > 0.3 — виден как рывок
```

## Чек-лист сдачи анимации

- [ ] Вращение задано скоростью, угол — интеграл; разрыв скорости 0
- [ ] Цикл замыкается: целые обороты, кратные частоты, хвост гаснет
- [ ] Ни одного `Math.abs(sin)` там, где это подъём, а не удар
- [ ] Жесты входят и выходят с нулевой скоростью (оболочка)
- [ ] Внутри жеста ноль промежуточных остановок; покой — параметр
- [ ] `kin.mjs` чисто или только «излом» там, где резкость намеренная
- [ ] `clip.mjs`: ни одного касания края на 40 моментах
- [ ] `dead.mjs`: ноль мёртвых ручек
- [ ] Инверсия: фигура не изменилась, тень и контакты читаются
- [ ] Раскадровка глазами (8 кадров за цикл) — движение читается как задумано

## Грабли

1. **Артефакт метрики принимается за баг.** Прежде чем чинить «незамкнутый цикл» —
   проверить, верно ли скрипт угадал период (у приёма может не быть ручки `period`).
2. **`Math.abs` в метрике угла.** Разворачивать угол (unwrap) перед дифференцированием,
   иначе переход через ±π даст фантомный разрыв в каждом замере.
3. **Снимок без заморозки.** `scrollIntoView` + скриншот ловит кадр до пересчёта размера —
   и стенд «находит» касание края, которого нет.
4. **Резкость по замыслу — не дефект.** Тик, подмиг, встряска, уворот обязаны щёлкать.
   Стенд их показывает; решение оставить принимается осознанно и записывается.
