# Interaction · Camera · Gizmo · Motion pad · Reveal · Pills

## Камера и drag
- Дом = вид сверху ¾ (`tilt` отрицательный, ≈ −28…−32). **Tilt без клэмпов** — полный оборот, можно
  смотреть сверху/снизу. drag: `yaw += dx·0.3·k`, `tilt −= dy·0.25·k` (k=2 если тянут за гизмо).
  wheel: `dist = clamp(dist·exp(dy·0.0012), 2, 7)`.
- Конвенция вращения «точка под рукой идёт за рукой» (для непрозрачных сцен — как башни/пирог —
  горизонталь в одну сторону; детали в grammar исходников).

## XYZ-гизмо (обязателен во всех билдерах)
Правый-низ `{x:W−72, y:H−72}`, r≈46. Круг-подложка (paper .85). Полуоси из `vT(unit,cm)`, отсортированы
по z: **X=accent · Y=ink · Z=muted**, ближняя ярче, отрицательная — пунктир, подпись у конца. Драг ВНУТРИ
круга вертит модель с ×2 чувствительностью. Прячется по H (чистый PNG).

## Motion pad (`@motion-core`)
Один 2D-регулятор вместо кучи speed/easing. Углы: **slow · fast · soft · raw**; точка билинейно смешивает
4 архетипа → `{speed, ease(t)}`.
```
ARCHETYPES = { slow:{.55, cos-ease}, fast:{1.9, 1-(1-t)^3}, soft:{.85, smootherstep}, raw:{1.3, t} }
motionResolve(x,y) → {speed, ease};  speedToX(target,y) для обратной синхры
```
`state.motion={x,y,speed}`. Speed-слайдер двусторонне синхронен с падом. Дефолт — мягкий S
(`x≈.14, y≈.55`) → появление ease-in-out. Мини-preview eased vs linear под падом.

## Reveal (появление) + транспорт
`revealFactors(t, easeFn, hold)` → множители по стадиям + `rise(d)` со стаггером (d — нормированная
дистанция/глубина: центр/внутреннее первым) + интро-полуоборот `yawOff` и доводка `tiltOff`. `state.anim=
{t,loop,hold}`. Пад: X=темп, Y=характер. Транспорт снизу по центру `#mtrans`: **⟲ Replay · Loop · Hold**
(dwell перед выходом). Появление гейтится перехватом альфы / множителями стадий (`labK` для подписей).

## Подписи-пилюли (канон + depth-occlusion)
Персистентные, ключ = имя узла/точки. Каждый кадр:
1. **lerp-трекинг** к якорю (top-центр объекта), fps-независимо `f=1−pow(1−0.2, dt·60)`.
2. **Релаксация** коллизий (10 итераций): расталкивание по меньшему перекрытию box + clamp в экран.
3. **Depth-occlusion (правило Роба):** доля пилюли, перекрытая гранями БЛИЖЕ её якоря. Сэмплим box
   4×3=12 точек; для каждой ищем грань с `fc.z < az−0.01` (ближе), отсев по bbox грани, затем `inPoly`.
   Если covered > **0.7** → цель `vis=0`, иначе 1. Альфа `a` лерпит к vis (fps-незав.).
4. **Анимация «пук»:** масштаб `= eob(a)` (ease-out-back, перелёт ~1.1) вокруг центра пилюли; при
   `a<0.02` — не рисуем. Так пилюля не проходит сквозь высокие шкалы: гаснет+сжимается, возвращается «пуком».
5. **Клик по пилюле = выбор** (приоритет над кликом по геометрии — легче попасть); кликабельны только
   видимые (`al>0.5`). Выбранная = accent, линия-привязка к якорю.

Для (3) каждой грани в рендере нужен screen-bbox — считается в момент постройки квада (дёшево).

## H и презентационный режим
`H` (когда фокус не в input) → `body.noui` прячет панель, хинт, транспорт и гизмо. Клик по объекту/пилюле
работает и при спрятанном UI (артефакт становится презентацией).
