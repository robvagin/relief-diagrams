# Verification — как проверять перед сдачей (обязательно)

Правило: не сдавать «на глаз в голове». Прогоняй каждый билдер тремя ситами. Всё делается без браузера
(node + headless SVG→PNG), результат смотрится глазами по превью.

## 1. Синтаксис
Вынуть `<script>…</script>` и `node --check`.
```
awk '/<script>/{f=1;next}/<\/script>/{f=0}f' Builder.html > /tmp/b.js && node --check /tmp/b.js
```

## 2. @core-ассерты (чистая математика, без DOM)
Вынуть блок `@core-begin … @core-end` (там НЕТ обращений к DOM — специально) и прогнать инварианты в node.
Что проверять по типам:
- **Раскладка данных:** биннинг сохраняет число точек; спан сегмента ∝ значению; топ-кольцо = полный круг.
- **Маппинг высоты `hmap`:** монотонность, `f(0)=0`, `f(1)=1` для linear/sqrt/log.
- **Motion:** fast.speed > slow.speed; `ease(0)=0`, `ease(1)=1`; `speedToX` — обратная синхра.
- **Reveal:** стаггер (центр/внутреннее раньше края); `baseK` доходит до 1 на settle.
- **Сортировка/окклюзия:** смоделировать 2 объекта (ближний-низкий vs дальний-высокий) и проверить, что
  ключ сортировки ставит ближний ПОСЛЕ (поверх). NB: геометрию near/far проверять ПО ФАКТУ через
  `vT(...).z`, а не по интуиции — при отрицательном tilt верх бывает ДАЛЬШЕ низа.
- **Пилюли depth-occlusion:** пилюля за ближней гранью → `occFrac≈1` (прячем); перед ней → `0`;
  `eob` даёт перелёт >1.05 (пук).

## 3. Визуальные превью (SVG → cairosvg → PNG → смотреть)
Собрать сцену теми же функциями ядра, вывести SVG, сконвертировать и посмотреть с 3–4 РАКУРСОВ
(разные yaw + один overhead). Проверить глазами:
- стенки высоких целы со всех ракурсов, дальнее уходит за ближнее, швов нет;
- дом = вид сверху ¾ (видны крышки), пилюли привязаны и разведены;
- пресеты дают разный масштаб/вид.
```
python3 -c "import cairosvg;cairosvg.svg2png(url='a.svg',write_to='a.png',output_width=760,output_height=560)"
```
(cairosvg ставится `pip install cairosvg --break-system-packages`; экранировать `&` в текстах для SVG.)

## Ловушки окружения (bash)
- zip прямо в mnt-путь может дать 0 байт → зиповать в `/tmp`, затем `cp` в Projects.
- `rm` иногда не проходит по некоторым файлам — перезапись Write работает.
- Юнит-тест «interleave» легко перепутать по знаку: при `tilt<0` верх дальше низа — считать `vT(...).z`.

## Гейт сдачи
syntax OK · все @core-ассерты pass · превью с ≥3 ракурсов читаются · экспорт SVG/PNG/config не падает ·
для дата-билдера — round-trip JSON (сериализовал → распарсил → та же раскладка).
