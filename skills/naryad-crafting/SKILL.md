# Naryad Crafting — формат жёсткого прогона

Образцы-первоисточники (читать при сомнении в тоне/плотности): `Projects/client_ATOM_TERMINAL_ORDER_2026-08-09.md` · `Projects/client_ГИЛЬОШ-ВОРКЕРЫ_НАРЯД_2026-08-25.md` (+`НАРЯД-2`) · `Projects/client_ГИЛЬОШ-ДАШБОРДЫ_НАРЯД_2026-08-26.md`. Исполненный лог с находками: `Projects/guilloche-workers/NOTES.md`.

## 1 · Скелет наряда (порядок секций фиксированный)

1. **Шапка**: «Единственный документ задачи» · дата · режим (Opus/ultracode/параллельные агенты) · рабочая папка · родственные доки.
2. **Задача в шесть строк** — что строим и что НЕ строим; объявление, что списки закрытые.
3. **Формат сдачи** — файлы таблицей; правила стенда (живые ячейки-атласы, подписи = id из кода, «взять», размеры приёмки 1280/768/390/320×240, ?embed=1).
4. **Что уже есть — берём, не пишем заново** — доноры ТОЧНЫМИ путями, проверенными на диске в день написания; у каждого — «как использовать» и чего не трогать. Плюс «что придётся дописать».
5. **Законы** (10–12) — нарушение любого = отказ приёмки независимо от красоты кадра. Каждый закон — одно проверяемое утверждение с причиной.
6. **Карты/списки** — закрытые перечни (тела, состояния, виды…) таблицами: id · суть · оси в грамматике `[key,label,min,max,step,def]` · примечание. «Придумалось ещё — строкой в NOTES.md, не делать».
7. **Механики** — сердце: формулы, таблицы профилей числами (реперные, «глаз доводит»), API.
8. **Справочник констант** — палитра/токены, тайминги, лестницы, пружины. Ничего «по вкусу исполнителя».
9. **Признаки штампа** — чего в кадре быть не должно (анти-слоп, 5–7 пунктов по жанру).
10. **Фазы** — Ф0 рельс (один агент, блокирующая) → Ф1 параллельные агенты по СВОИМ регионам → стенд → приёмка. Рез-порядок под срок + «не режется никогда». Числа приёмки считаются ПОСЛЕ реза.
11. **Приёмка** — независимый headless-харнесс, file://; пробы поимённо (см. §3).
12. **Правила для агентов** (см. §4) и **Чего делать не надо** — по одному глаголу на грех.

## 2 · Законы формата

- **Самодостаточность**: исполнитель не должен открывать другие доки, кроме названных донорами; несущее из ресерчей ПЕРЕНОСИТСЯ в наряд.
- **Закрытые списки**: ни одной оси/значения сверх названных; новое — строка в NOTES.md.
- **Доноры путями**: каждый путь проверен `ls`/grep в день написания; «взять verbatim» ≠ «переписать по мотивам».
- **Профили числами**: поведение задаётся таблицами величин, не прилагательными. Помечать реперное («глаз доводит»).
- **needs-human помечается заранее**: вкусовые вердикты — отдельными пунктами «глаз Роба», они входят в приёмку.
- **Сдача — только открывающийся HTML** (или файл-артефакт), никогда текст/скриншот/описание.
- **Волна-2 начинается с вердиктов**: новая волна поверх постройки открывается таблицей решений по открытым пунктам NOTES предыдущей (вес, спорные механики, «ждёт глаза») — исполнитель не должен тащить старые вопросы.

## 3 · Приёмка: обязательные пробы и ловушки замеров

Базовый набор: живость счётчиками (`__X_FRAMES/__READY/__ERROR` — страница бывает нарисована, но мертва) · детерминизм (сид ×2 → FNV-отпечаток) · грепы (range-инпуты 0 · Math.random/Date.now 0 · хексы вне токен-блока 0 · запрещённые изинги 0 · сеть 0) · reduced-motion · embed 320×240 · перф-бюджет числом · blind-read глазом (человек называет состояния/данные без подписей, порог вида ≥7/9).

**Ловушки замеров** (каждая стоила времени — вписывать в наряд предупреждением):
1. Сперва докажи, что замер вообще что-то поймал (ручка доезжает? mount читает params?).
2. Сперва размах, потом частота: перепад <~4% — шум растра, частоты там нет.
3. rAF ≠ 60 Гц (бывает 120) — время только по часам; контрольный синтетический сигнал обязан измериться правильно.
4. Насыщенная метрика (например «% изменённых пикселей») врёт увереннее шумной — спорное решает глаз на контакт-листе.
5. Пиксельная метрика толщины меряет состав кадра, не ширину штриха — не единственное доказательство.

## 4 · Правила для агентов (вставлять блоком)

1. Файлы по частям: Write скелета → Edit секциями (целиком одним сообщением — смерть по лимиту вывода).
2. Код в финальный ответ не выводить; ответ — 8–12 строк: что построено, чем проверено, что осталось.
3. Свои файлы/регионы; рельс правит только Ф0; один владелец файла в момент времени.
4. Не нашёл — скажи «не нашёл»; догадка за факт возвращается приёмкой.
5. Спорное — в NOTES.md, не в голове; срезанное — строкой, молча не выкидывается.
6. Headless-прогон и `node --check` (на извлечённом `<script>`) перед сдачей; собранные файлы руками не править — правится шаблон.
7. git: атомарный коммит на зелёную фазу, галочка+хэш аппендом в наряд/NOTES.

## 5 · Тон

Императив, плотно, без воды; таблицы вместо абзацев; 🔴 только на действительно несущем; каждое «нельзя» — с причиной в одну фразу (исполнители умные — им нужно «почему», а не капс). Запуск наряда — одна вставка: «Читай <путь>, исполняй фазы сверху вниз, автономно».
