# ПАСПОРТ ФРАГМЕНТА · 03-stack-sphere

**Файл:** `fragments/03-stack-sphere/index.html` · single-file, zero-dependency, работает по `file://`.
**Что это:** псевдо-3D шар, набранный стопкой эллипсовых дисков. Семь дисков = семь пунктов
стека client, сверху вниз: LLM → Agentic Harness → Context & Knowledge → Data & Integrations →
Real Estate Capabilities → Interface → Security & Governance.

---

## Как вставлять

```html
<div class="stack-sphere-mount">
  <iframe src="fragments/03-stack-sphere/index.html?embed=1"
          title="client OS stack" loading="lazy"
          style="width:100%;height:100%;border:0;display:block"></iframe>
</div>
```

- Пропорция: **3 : 2** (ширина : высота). Минимальная высота **560 px**, комфортная **700–820 px**.
- Фон фрагмента совпадает с грунтом страницы (`#EBE8DF`), рамки и теней вокруг iframe не нужно.
- На 390 px фрагмент остаётся во всю ширину, высоту брать не меньше 520 px.

## Параметры адреса

| Параметр | Значение | Зачем |
|---|---|---|
| `?embed=1` | обязателен | прячет панель, полку и подсказки — остаётся чистая сцена |
| `&theme=night` | опционально | тёмная сторона на night-токенах |
| `&p=0.35` | опционально | показать кадр на 35 % сборки — для проверки без скролла |

## Привязка к скроллу (у них это «Scroll through the stack»)

Фрагмент сам скролл не слушает — им управляет страница. Вставить рядом:

```html
<script>
(function () {
  var wrap = document.querySelector('.stack-sphere-mount');
  var frame = wrap.querySelector('iframe');
  function tick() {
    var r = wrap.getBoundingClientRect();
    var vh = window.innerHeight;
    var p = (vh - r.top) / (vh + r.height);       // 0 — секция под экраном, 1 — ушла вверх
    p = Math.max(0, Math.min(1, p));
    frame.contentWindow.postMessage({ type: 'es:progress', value: p }, '*');
  }
  addEventListener('scroll', tick, { passive: true });
  addEventListener('resize', tick);
  tick();
})();
</script>
```

Пока сообщение не пришло, фрагмент играет сборку сам по таймеру — то есть и без скрипта
секция выглядит живой. Первое же `es:progress` переключает его на управление снаружи.
`{type:'es:replay'}` возвращает автоигру.

## Что ЗАМОРОЖЕНО — не трогать

Внутри фрагмента настроены и зафиксированы: число слоёв (7), силуэт, наклон, крен, перспектива
по стопке, темп сборки, веер, дыхание, тон бронзы, градация по слоям, кант, тени, кегль и коридор
подписей. **Это не дефолты «на глаз» — это принятый Робом пресет.** Менять их в вёрстке нельзя:
ни через CSS-фильтры, ни через `transform`, ни масштабированием iframe. Нужна другая настройка —
запрос нам, мы пересобираем фрагмент.

Также нельзя: перекрашивать сцену, накладывать оверлеи поверх канваса, обрезать фрагмент по высоте,
подменять подписи вёрсткой (они живут внутри и участвуют в раскладке выносок).

## Что фрагмент делает сам

- **Приезд:** блинчики собираются сверху вниз один за другим, мягкий ease-out, без отскока.
- **Ховер по сцене:** стопка чуть раскрывается.
- **Ховер по блинчику:** диск выдвигается вбок, его пилюля становится акцентной, под ней сноска.
- **Клик по блинчику:** диск доворачивается лицом и рядом всплывает карточка — сноска, три
  строки «ключ — значение» и полоска места слоя в стопке. Повторный клик или `Esc` закрывают.
- **Выноски:** два коридора слева и справа, один излом, сортировка по вертикали — линии не пересекаются.

## Состояния

| Состояние | Поведение |
|---|---|
| Загрузка | канвас сразу заливается грунтом, сборка стартует — белого мига нет |
| `prefers-reduced-motion: reduce` | сборка и дыхание выключены, показан финальный кадр; ховер и клик работают |
| Клавиатура | ⚠️ сцена пока не фокусируется с клавиатуры. Секция должна оставаться понятной **без** фрагмента: семь пунктов стека обязаны быть в вёрстке текстом (можно визуально скрытым списком) — фрагмент их иллюстрирует, а не заменяет |
| Узкий экран | работает; на 390 px подписи ужимаются, стопка остаётся целой |
| Тёмная тема | `?theme=night`, ночные токены |

## Живость

`window.__ES_FRAMES` растёт каждый кадр, `window.__ES_READY === true` после первого кадра.
Если понадобится проверить, что фрагмент не «нарисован и мёртв» — смотреть на них, а не на скриншот.
