# Шаблоны

`example-stack-sphere.html` — живой пример фрагмента, собранный по этому скиллу: слоёный шар client,
семь дисков = семь пунктов стека, пресет заморожен, `?embed=1`, `?theme=night`, `?p=0..1`,
привязка к скроллу через `postMessage`, автоигра как фолбэк. Открывать двойным кликом.

Паспорт к нему — `references/PASSPORT_EXAMPLE.md`. Это не абстрактный образец: файл реально ушёл
в пак для Claude Design 2026-08-10.
