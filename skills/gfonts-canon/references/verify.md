# Протокол проверки

Цель — ни одного имени, веса, оси или фичи по памяти.

## 1. Существует ли семейство

Основной источник — репозиторий, из которого Google Fonts и раздаёт шрифты. Слаг = имя в нижнем регистре без пробелов (`Source Serif 4` → `sourceserif4`, `Big Shoulders Display` → `bigshouldersdisplay`).

```
https://raw.githubusercontent.com/google/fonts/main/ofl/<slug>/METADATA.pb
https://raw.githubusercontent.com/google/fonts/main/apache/<slug>/METADATA.pb
https://raw.githubusercontent.com/google/fonts/main/ufl/<slug>/METADATA.pb
```

HTTP 200 = семейство есть. 404 по всем трём каталогам = семейства нет, так и писать. Большинство лежит в `ofl/`.

`METADATA.pb` даёт: категорию, дату добавления, дизайнера, список начертаний и — главное — блок `axes {}`. Он генерируется машинно из таблицы `fvar` реальной сборки, то есть это авторитетный источник по осям и диапазонам, а не описание из маркетинга.

## 2. Что Google пишет на странице образца

```
https://raw.githubusercontent.com/google/fonts/main/ofl/<slug>/DESCRIPTION.en_us.html
```

Это дословный текст вкладки About на fonts.google.com. Отсюда берутся формулировки словолитни про назначение («for continuous on-screen reading», «is a display typeface») и про контраст. Цитировать в кавычках. У части семейств файла нет — тогда искать первоисточник у автора.

## 3. Проверка осей через CSS2 API

```
https://fonts.googleapis.com/css2?family=<Family+Name>:wght@100..900
https://fonts.googleapis.com/css2?family=<Family+Name>:wdth,wght@75..125,100..900
```

Ключевой приём: **запрос несуществующей оси возвращает HTTP 400**. Это жёсткое доказательство отсутствия, а не догадка. Запрос существующей возвращает настоящие правила `@font-face` с `font-stretch`.

⚠️ Из песочницы `fonts.google.com` и `fonts.googleapis.com` могут быть недоступны по сетевой политике (403 на CONNECT). Это блокировка маршрута, не отсутствие данных — тогда работать через репозиторий из пунктов 1–2 и через двоичные файлы из пункта 4. То же ограничение значит, что **скриншот типографики из песочницы всегда в фолбэке** — вебшрифты там не подгрузятся. Рендер смотрит человек у себя.

## 4. OpenType-фичи по двоичному файлу

Единственный честный способ ответить про цифры. Скачать сборку из того же репозитория и прочитать GSUB:

```python
from fontTools.ttLib import TTFont
f = TTFont("Family[wght].ttf")
print(sorted({r.FeatureTag for r in f["GSUB"].table.FeatureList.FeatureRecord}))
```

Что искать: `tnum` табулярные · `pnum` пропорциональные · `lnum` капитальные · `onum` старостильные · `zero` перечёркнутый ноль · `frac`/`afrc` дроби · `ss01…`/`cv01…` стилистические сеты и альтернативы.

Если фичи нет в GSUB — писать «нет», даже когда автор в changelog обещает обратное: сборка на Google Fonts отстаёт от апстрима, и в браузере у пользователя окажется именно она.

## 5. Ранг распространённости

Google публикует Analytics по семействам, но страница часто недоступна из автоматизации. Рабочий обходной источник — архив того самого JSON, на котором она работает:

```
https://github.com/radames/google-fonts-analytics-archive → stats.json
```

Содержит все ~1951 семейство с полями совокупных просмотров и просмотров за последние 365 дней. **Сортировать самому, кодом**, а не просить модель прочитать файл — при пересказе легко получить порядок, похожий на алфавитный, и не заметить.

Два числа на семейство: ранг за всё время (насколько заезжено) и ранг за год (куда движется). Расхождение информативно: Manrope #60 за всё время, но #30 за год — то есть прямо сейчас входит в топ-30. Chivo #188 за всё время и #226 за год — выходит из моды.

Независимая перекрёстная проверка: **HTTP Archive Web Almanac, глава Fonts** (`almanac.httparchive.org/en/2024/fonts`) — доля реальных сайтов в краулинге. Другая методика, поэтому совпадение верхушки = хорошая валидация. Almanac ловит и самохостинг: Inter в Google-CDN-выдаче ниже, чем его реальная распространённость, потому что его массово хостят у себя.

Это единственный объективный способ ответить на «не сильно запопсованный». Без данных — писать «не подтверждено», а не выдавать ощущение за факт.

🔴 **Проверять свежесть архива перед каждой выдачей.** Он зеркалит чужой репозиторий, и зеркало может встать. Проверка занимает минуту: взять несколько семейств, добавленных на Google Fonts за последние месяцы (по `date_added` в `METADATA.pb`), и посмотреть, есть ли они в `stats.json`. Если нет — архив отстаёт минимум на этот срок. **На 2026-08-09 он отставал минимум на 40, вероятно до 60 дней**: отсутствовали Caacupe One (01.07), Scoutie Sans (02.07), Nevermind (24.07), Valley Sans (29.07.2026). Ежедневный cron, судя по всему, отключён GitHub'ом за неактивность репозитория. Отставание не делает ранги бесполезными — верхушка двигается медленно, — но выдавать их надо как **снимок с датой**, а не как текущее состояние.

## 5-бис. Полный каталог одним запросом

```
https://fonts.google.com/metadata/fonts
```

Отдаёт JSON со **всеми** семействами (на 2026-08 их 1942) — имя, категория, `stroke`, начертания, оси. Это единственный способ честно ответить на вопрос вида «а есть ли на GF вообще X» — фильтром по всему каталогу, а не перебором догадок. У этого URL отдельный сетевой путь: он бывает доступен даже когда `fonts.google.com/specimen/...` и CSS2 API заблокированы.

Это обязательный шаг перед любым утверждением «такого там нет». Мы один раз написали «узких серифов на Google Fonts не существует» по десяти ответам 404 — и ошиблись: **Stint Ultra Condensed** (`category: SERIF`, `stroke: SLAB_SERIF`) существует с 2011 года, а **Playfair** (отдельное семейство, не Playfair Display) несёт `wdth 87.5–112.5` и `opsz 5–1200`.

## 6. Ссылка для человека

```
https://fonts.google.com/specimen/<Family+Name>
```

В таблице имя семейства всегда ссылка — человек кликает и смотрит живьём. Это компенсирует то, что рендер из песочницы недостоверен.

## Порог доверия

| Утверждение | Чем подтверждается |
| --- | --- |
| Семейство существует | 200 на `METADATA.pb` |
| Веса и оси | блок `axes {}` в `METADATA.pb`, либо 400/200 от CSS2 |
| Назначение (текст/дисплей) | цитата из `DESCRIPTION.en_us.html` или с сайта автора |
| Цифры и фичи | GSUB двоичного файла |
| Распространённость | `stats.json`, отсортированный кодом |
| Контраст, рост строчных | оценка — помечать как оценку, если нет цитаты |
