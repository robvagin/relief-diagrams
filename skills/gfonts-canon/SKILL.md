# Канон Google Fonts

## Два железных закона

**1. Ноль имён по памяти.** Модель уверенно галлюцинирует гарнитуры, веса, оси и OpenType-фичи. Каждое имя в выдаче обязано быть проверено на живом источнике за эту сессию — см. `references/verify.md`. Что не подтвердилось, в выдачу не попадает; что подтвердить не удалось, помечается словами «не подтверждено», а не выбрасывается молча.

**1-бис. Никаких универсальных отрицаний.** «Такого на Google Fonts нет вообще» — самое опасное утверждение, его убивает один контрпример. Проверка десяти очевидных имён и десять ответов 404 **не доказывают отсутствие класса**: это доказывает только то, что эти десять имён не существуют. Класс может быть реализован иначе — через ось внутри семейства, а не через отдельное имя. Прежде чем писать «нет вообще», прогнать полный каталог (`fonts.google.com/metadata/fonts` отдаёт все ~1940 семейств с категорией и `stroke`) и отфильтровать по признаку. Мы уже наступили на это ровно один раз — см. запись про узкие серифы в `references/catalogue.md`.

**2. Кандидаты, а не решение.** Отдаётся список вариантов с фактическими атрибутами, по которым человек судит сам: веса, оси, контраст штриха, рост строчных, цифры, парный санс, ранг распространённости, ссылка на образец. Собранные пары, применение на макет, «рекомендую эту» — **только по прямой просьбе**. Факты и занятость поля (что уже занято конкурентами, где сломаны фигуры, где ось реально есть) — это материал, а не решение, их давать нужно.

## Порядок работы

1. **Снять ограничения.** Только Google Fonts или можно шире? Нужна кириллица? Нужен курсив? Нужны табулярные цифры (есть ли в интерфейсе цены, таблицы, счётчики)? Какой язык интерфейса — у кириллицы другой рост строчных и другой трекинг.
2. **Посмотреть, что занято.** Прежде чем предлагать — проверить, чем набраны прямые конкуренты. Совпасть с ними шрифтом = потерять отличие. Это отдельный шаг, его пропускают чаще всего.
3. **Проверить каждого кандидата** по протоколу из `references/verify.md`.
4. **Снять ранг распространённости** — объективно, по данным, а не на ощущение. Протокол там же.
5. **Разложить по группе и отсортировать** по признаку, который решает задачу: серифы — по контрасту штриха, гротески — по рангу, конденсы — по глубине сужения.
6. **Выдать таблицей.** Поля — ниже.

## Поля на каждую гарнитуру

| Поле | Что писать |
| --- | --- |
| Название + ссылка | `fonts.google.com/specimen/<Family>` |
| Веса | Диапазон; вариативная или статика; если статика — перечислить |
| Оси | wght / wdth / opsz / slnt / ital / кастомные, с точными диапазонами. «нет» если статика |
| Контраст штриха | Низкий / умеренный / высокий. Для серифов — обязательное поле |
| Рост строчных | Большой / средний / малый, относительно остальных в списке |
| Курсив | Есть или нет. Отсутствие курсива — частая и незаметная дыра |
| Цифры | tnum / lnum / onum / pnum / zero — по GSUB или документации. «не документировано», если первоисточника нет. Не угадывать |
| Парный санс или сериф | Название семейства-компаньона или «—» |
| Ранг | Место по распространённости + тренд |
| Оговорка | Одна строка реального ограничения |

Формулировки словолитни давать **в кавычках**, свою оценку — без. Их нельзя смешивать: «foundry пишет "low stroke contrast"» и «на глаз низкий» — разной силы утверждения.

## Что чаще всего оказывается неправдой

Проверенные ловушки — держать в голове, они повторяются:

- **Название с «Condensed» / «Caption» / «Display» / «SC» не значит того, что кажется.** *PT Serif Caption* — оптический крой под мелкий кегль, не узкий. *Playfair Display SC* — капитель. *Zilla Slab Highlight* — пасхалка Mozilla с лигатурой «mozilla» → «moz://a». *Big Shoulders Text* всё равно лежит в категории Display.
- **Отсутствие курсива.** Roboto Slab, Domine, Solway, Podkova, Bricolage Grotesque, Encode Sans целиком, Eczar, большинство готиков — курсива нет вообще. Всплывает поздно и ломает иерархию.
- **Диапазон веса не 100–900.** Vollkorn, Alegreya, Besley, Eczar, Bodoni Moda, Gabarito — с 400. Manrope — потолок 800. Space Grotesk — 300–700. Andada Pro — верх 840. Cabin — 400–700.
- **Один вес.** Libre Caslon Display, Anton, Bebas Neue, Abel, Six Caps, League Gothic, Crete Round.
- **Дефолт вариативной оси уводит рисунок.** У Fraunces в самом файле дефолты **WONK 1 · SOFT 0 · wght 900 · opsz 9** — то есть сырой вариативный файл открывается чёрным, в мелком оптическом крое и в «wonky»-режиме. Archivo по умолчанию wdth 100 — выглядит как повсеместный Archivo Black, пока ось не покрутить. Дефолты читать из `fvar` бинарника, а не из головы: в `METADATA.pb` их нет, там только min/max.
- **«Статика» — тоже утверждение, и оно протухает.** Семейства переезжают в вариативные, а старая запись переживает переезд. Мы записали IBM Plex Sans статикой — он вариативный, с осью `wdth 75–100`. Проверять блок `axes{}`, а не помнить.
- **Кириллица есть далеко не везде, и это не видно по имени.** Без кириллицы: Archivo, Public Sans, Petrona, Newsreader, Outfit, Urbanist, Jost (есть базовая, без ext), Red Hat Display, League Spartan, Josefin Sans, Cabin, Lexend, Assistant, Signika. Отдельная ловушка — семейства, где есть **только `cyrillic-ext` без базового `cyrillic`**: Merriweather Sans, Plus Jakarta Sans. Проверять поле `subsets` в `METADATA.pb`.
- **Сломанные фичи.** У EB Garamond не работает переключение стилей цифр. У Host Grotesk changelog обещает tnum, а в сборке на GF его нет — сборка GF отстаёт от апстрима.
- **Семейства, которых на Google Fonts нет.** General Sans, Switzer, Aspekta, любые Helvetica-производные и Neue Haas. Их регулярно предлагают по памяти.
- **Ширина осью против ширины семейством.** У Sofia Sans оси wdth нет — узкое берётся выбором другого имени семейства. У Inter Tight оси wdth тоже нет, это поджатые апроши.

## Направления

Полная карта с примерами — `references/directions.md`. Коротко: **направление задаёт не «красивость», а регистр доверия**. Скептичной аудитории нужен спокойный регистр; молодой аудитории — характер; финансам — институциональность. Одна и та же гарнитура может быть верной и провальной в зависимости от того, что говорит текст.

## Цифры

Если в интерфейсе есть цены, таблицы, счётчики или даты — **фигуры это критерий отбора, а не придирка**. Дисплейная гарнитура несёт заголовки, а все числа идут через текстовую с подтверждёнными табулярными цифрами. Подтверждённые носители — в `references/catalogue.md`.

## Каталог

`references/axes.md` — полный индекс вариативных осей каталога: 95 семейств с `wdth`, 27 с `opsz`, 22 со `slnt`, `GRAD`, и все кастомные оси с описанием того, что каждая физически делает. Ось — самое дешёвое отличие: `wdth` крутит меньше пятой части тех, у кого она есть.

`references/catalogue.md` — проверенные семейства по группам: серифы по контрасту, слэбы, гротески по рангу распространённости, конденсы и семейства с настоящей осью ширины, текстовые и интерфейсные. Это снимок на дату в шапке файла: Google Fonts пополняется, ранги двигаются. Перед серьёзной выдачей — **переснять ранги** и проверить, не появилось ли нового; каталог ускоряет работу, но не заменяет проверку.
