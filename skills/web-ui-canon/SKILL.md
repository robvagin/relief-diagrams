# Web UI Canon — вкус Роба для веба (дистилляция)

Полный канон: `Projects/WEB_UI_CANON.md` (при расхождении — он главнее).
Роли: **Claude строит каркас по канону; брендовые акценты, игра, полишинг — слой Роба.** Не изобретать брендовые жесты самовольно.

## Закон №1 — радиусы по регистрам

- Нейтралка = **4–6px**. Строгач = **0px** (прямые углы, всё конкретно). Пилюля 999 = дружелюбно-коммерческий регистр или геометрическая игра.
- 🔴 **10–14px на кнопках — бан навсегда.**
- Вложенность: материнская плашка задаёт внешний радиус, всё внутри согласовано через паддинг (inner = outer − padding). Один язык углов на макет.

## Закон №2 — поверхности

- Карточка-дефолт: **тинт-заливка без бордера и тени**. Тень — едва заметная однослойная, если нужна. Бордер — редкий акцент: бордеры везде = визуальный шум = блок.
- Разделители: линии в данных/таблицах, воздух в маркетинге. Обводки — минимум (исключение: инпуты).
- Чипы/бейджи/теги — **только полная пилюля** (мелкая пилюля читается как тег; 4–6px/прямые читаются как мини-кнопка или недоработка).

## Закон №3 — типографика (поверх TYPOGRAPHY_CANON)

- Шкала спокойная ~×1.2; контраст добирается ВЕСОМ и деталями: заголовок капельку крупнее и толще, подзаголовок — с увеличенной разрядкой. Заголовок ≠ подзаголовок по размеру/весу никогда. ×1.33 — дурное соотношение (конфликт с межстроком).
- Hero десктоп 64–80px. Body 16px, мера 60–70ch. Весов ≤4. Eyebrow — строчный тихий.
- Без брендбука: один гротеск (Inter-класс); моно — системный macOS-класс (SF Mono-подобный), не дефолтный.
- 🔴 Italic serif — бан. Деформация/искажение шрифтов — бан.
- Визуальный темп: чередование сторон в повествовании; база — швейцарская сетка.

## Закон №4 — цвет

- Светлый фон: **#f6f5f2**. Тёмные секции — редко (финальный CTA/футер).
- Формула: один большой акцент с градациями + вспомогательный + 1–2 сверхъярких точки (только линии/точки/микродетали). Диапазон монохром↔полихром решает бренд.
- Градиенты — только едва заметные тональные. Семантика — приглушённые тинты в тон бренда. Текст на цвете — тёмный стоп той же гаммы. Коммерческие штампованные цвета — не использовать.

## Закон №5 — пространство

Секции 80–104px (плотно) · контейнер 1320–1440 · асимметрия 5/7, 4/8 с чередованием сторон (база, не догма — контекст решает) · плотность средняя · внутренний ритм пропорционально кеглю (em-логика) · фоновый ритм по повествованию.

## Закон №6 — кнопки и контролы

- Три уровня: primary/secondary/ghost. Sentence case. Без иконок (чистый текст).
- Высота не в px — от ритма бренда: крупное контрастное → крупные, тонкое строгое → компакт.
- Ховер: смягчение/затемнение тона заливки. Инпуты: обводка (сигнал зоны ввода); заливка-оттенок, если бренд без обводок; нижняя линия — строгие бланки. Focus-visible: мягкое кольцо в тон акцента, без офсета.

## Закон №7 — движение

Сдержанный бюджет: ховеры + деликатные появления. Scroll-reveal: все секции fade + минимальный move. Темп 300–500ms, мягкий ease. Блюр в навигации не перебарщивать.

## Закон №8 — дирекшны

Обойма: Swiss-строгач · Editorial · Генеративный/виз · Timeless-люкс. Самые «наши» — строгач и Timeless. Декор (guilloché, поля, зерно) — только по брендбуку. Медиа без клиентских фото — наша абстрактная генеративка. Цифры/статистика — секции с визуализацией.

## Слоп-блэклист (блокеры сдачи)

10–14px кнопки · фиолетовые AI-градиенты · эмодзи в заголовках · 3 колонки фич с иконками в кружках · оверрадиус 16–24 на всём · жирные тени повсюду · italic serif · деформация шрифтов · чипы не-пилюли · бордеры как система · штампованные цвета · заголовок = подзаголовок.

## Приёмка

Три ширины параллельно 360/768/1200+ · скриншоты eyes.py перед сдачей · матрица состояний (ui-state-completeness) · орфаны через &nbsp; · кириллица проверяется отдельно.
